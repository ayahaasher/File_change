# File Modifier Pro - 跨平台文件改名与时间戳管理引擎

本项目是一款功能强大的文件管理工具，支持通过 **命令行 (CLI)** 或 **现代 Web UI (Dashboard)** 批量修改文件名（支持正则表达式）以及自定义文件时间戳（访问、修改、创建日期）。

特别针对 macOS/Windows 优化，支持修改文件的“诞生日期”（Birthtime），并具备智能的时间逻辑约束功能。

---

## 🌟 核心特性

-   **现代 Web 控制台 (Dashboard)**：基于 FastAPI 构建，提供极致视觉体验的玻璃拟态 (Glassmorphism) UI。
-   **全平台原生交互**：在 Web 端直接唤起 **macOS/Windows 原生文件选择对话框**，操作直观。
-   **实时监控 (SSE)**：通过流式技术实时推送任务进度，环形进度条与控制台同步反馈。
-   **任务历史与复用**：完整记录过往处理参数，支持“一键复用”历史任务配置。
-   **专业正则改名**：支持 Python 级正则表达式搜索替换及捕获组引用。
-   **时间戳随机化**：支持设置日期范围，为每个文件分配独立的随机时间点。
-   **智能逻辑约束**：自动确保“创建时间”早于“修改时间”，逻辑不严谨时自动修正。

---

## 🚀 快速开始 (Web UI)

推荐直接使用 Web 界面进行操作，具备更好的交互性与安全性：

1.  **启动 Web 服务**：
    在终端执行以下命令（脚本会自动创建 Python 虚拟环境并安装所需依赖）：
    - **macOS/Linux**:
      ```bash
      chmod +x start_web.sh
      ./start_web.sh
      ```
    - **Windows**:
      ```cmd
      start_web.bat
      ```
2.  **访问控制台**：
    在浏览器打开 [**http://127.0.0.1:8000**](http://127.0.0.1:8000) 进入管理面板。
3.  **开始任务**：
    -   点击“选择文件夹/文件”锁定目标。
    -   配置正则规则或时间区间。
    -   点击“开始处理任务”并在右侧实时监控。

## 💻 命令行使用 (CLI)

如果您更习惯使用命令行，可以继续调用 `file_modifier.py`：

| 参数 | 说明 |
| :--- | :--- |
| `-p`, `--path` | **核心参数**。目标文件或文件夹路径。 |
| `-r`, `--recursive` | 递归处理子文件夹中的所有文件。 |
| `--rename-pattern` | 文件名匹配的正则表达式。 |
| `--rename-replace` | 替换后的文本。支持 `\1`, `\2` 等反向引用。 |
| `--mtime` | 修改时间。格式：`YYYY-MM-DD` 或 `开始时间,结束时间`。 |
| `--ctime` | 创建时间。格式同上。 |
| `--dry-run` | **预览模式**，仅打印提示，不修改真实文件。 |

**示例**：将目录内 2025 年的时间戳全部随机化：
```bash
python3 file_modifier.py -p ./photos --mtime "2025-01-01,2025-12-31"
```

## 🛠️ 环境要求

-   **操作系统**：macOS 或 Windows (全功能支持)；Linux (支持重命名及 mtime/atime)。
-   **Python 版本**：Python 3.6+。
-   **平台特性**：
    *   **macOS**: 修改“创建时间”需安装 Xcode 命令行工具 (`SetFile`)。
    *   **Windows**: 支持原生创建时间修改，无需额外工具。
