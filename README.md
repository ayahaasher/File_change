# 文件改名与时间戳批量修改工具 (file_modifier.py)

这是一个功能强大的 Python 脚本，专门用于批量修改文件名（支持正则表达式）以及自定义文件时间戳（访问、修改、创建日期）。它特别针对 macOS 优化，支持修改文件的“诞生日期”（Birthtime），并具备智能的时间逻辑约束功能。

---

## 核心功能

1.  **正则批量改名**：使用 Python 正则表达式搜索并替换文件名，支持捕获组引用。
2.  **时间戳随机化**：支持设置固定日期或给定一个**日期范围**，脚本会为每个文件在该范围内独立随机取值。
3.  **智能时间约束**：
    *   **创建时间一致性**：自动确保“创建时间”早于“修改时间”。
    *   **自动修正**：若设置的修改时间早于文件当前创建时间，脚本会自动向前推移创建时间（加上随机偏移），确保属性逻辑合规。
4.  **安全预览 (`--dry-run`)**：在实际修改文件前，可以完整打印预览所有改名和时间调整的操作。
5.  **跨文件/目录操作**：支持单个文件目标或整个目录，具备递归处理功能。

---

## 环境要求

-   **操作系统**：macOS 或 Windows (全功能支持)；Linux (支持重命名及 mtime/atime)。
-   **Python 版本**：Python 3.6+。
-   **依赖项**：无需安装第三方库。
-   **平台特性说明**：
    *   **macOS**: 修改“创建时间”调用 `/usr/bin/SetFile`（需 Xcode 命令行工具）。
    *   **Windows**: 修改“创建时间”调用系统原生 API，无需额外安装。
    *   **Linux**: 暂不支持修改“创建时间”（受限于文件系统 API）。

---

## 参数详细说明

| 参数 | 说明 |
| :--- | :--- |
| `-p`, `--path` | **核心参数**。目标文件或文件夹路径。 |
| `-r`, `--recursive` | 递归处理子文件夹中的所有文件。 |
| `--rename-pattern` | 文件名匹配的正则表达式 (Python `re` 语法)。 |
| `--rename-replace` | 替换后的文本。支持 `\1`, `\2` 等反向引用。 |
| `--mtime` | 修改时间。格式：`YYYY-MM-DD` 或 `开始时间,结束时间`。 |
| `--ctime` | 创建时间 (macOS)。格式同上。 |
| `--atime` | 访问时间。格式同上。 |
| `--dry-run` | **建议开启**。预览模式，仅打印提示，不修改真实文件。 |
| `--include` | 正则过滤：仅处理符合此正则的文件名。 |
| `--exclude` | 正则过滤：排除符合此正则的文件名。 |

## 使用示例

### 1. 基础改名：删除特定前缀
将 `12313--report.doc` 改为 `report.doc`：
```bash
python3 file_modifier.py -p report.doc --rename-pattern "^12313--" --rename-replace ""
```

### 2. 时间随机化：将文件时间修改为 2025 年内的任意时间
脚本会自动确保生成的 `ctime < mtime`：
```bash
python3 file_modifier.py -p ./my_photos --mtime "2025-01-01,2025-12-31"
```

### 3. 指定固定创建时间与随机修改时间
```bash
python3 file_modifier.py -p document.pdf --ctime "2024-05-20" --mtime "2025-01-01,2025-12-31"
```

### 4. 复杂过滤与递归处理
仅对目录内 `.jpg` 结尾的文件进行重命名和时间修改：
```bash
python3 file_modifier.py -p ./project -r --include "\.jpg$" --rename-pattern "^IMG_" --rename-replace "Photos_" --mtime "2026-01-01"
```

### 5. 安全运行（预览）
强烈建议在执行大批量修改前先加上 `--dry-run`：
```bash
python3 file_modifier.py -p ./important_files --mtime "2023-01-01,2024-01-01" --dry-run
```

---

## 注意事项

-   **正则语法**：脚本使用 Python 的 `re` 模块。例如 `^` 表示开头，`$` 表示结尾，`\d+` 表示数字。
-   **时间格式**：支持 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM:SS`、`YYYY/MM/DD` 等常见格式。
-   **权限**：修改某些受保护的系统文件可能需要 `sudo` 权限。
-   **创建时间限制**：在非 macOS 系统上，由于操作系统限制，`--ctime` 可能无法生效或仅修改系统层面的 `ctime`（状态改变时间）。
